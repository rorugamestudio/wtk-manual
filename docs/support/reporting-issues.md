# Reporting Issues

Before opening a new issue, [search the existing ones](https://github.com/rorugamestudio/wtk-manual/issues?q=is%3Aissue) in case it has already been reported.

| I want to... | Use |
|---|---|
| Report something that doesn't work | [Bug Report](https://github.com/rorugamestudio/wtk-manual/issues/new?template=bug_report.yml) |
| Suggest a new feature or an improvement | [Feature Request](https://github.com/rorugamestudio/wtk-manual/issues/new?template=feature_request.yml) |
| Report a mistake or a gap in this manual | [Documentation](https://github.com/rorugamestudio/wtk-manual/issues/new?template=documentation.yml) |
| Ask how to do something | [Question](https://github.com/rorugamestudio/wtk-manual/issues/new?template=question.yml) |

## Writing a good bug report

- **Versions.** The World Toolkit version, the Unity version and the render pipeline you use.
- **Steps to reproduce.** Start from a new scene when you can, and list every step.
- **Expected and actual result.** What you thought would happen, and what happened instead.
- **Screenshots or a short video.** Especially for anything visible in the Scene view.
- **Console errors.** Copy the full message, including the stack trace, from the Unity Console.
